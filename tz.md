### 2.2 Страница "Возможности" (features.html)

#### Hero

- Заголовок: "Полный функционал для управления парковкой"
- Подзаголовок: "От распознавания номеров до финансовой аналитики"

#### Блок "Основной функционал" (Аккордеон или табы)

**1. Автоматическая регистрация**

- Фиксация въезда/выезда через камеры
- Распознавание номерных знаков (кириллица, латиница)
- Сохранение полных фото автомобилей и номеров
- Защита от дублирования событий (60 секунд)
- Привязка камер по IP-адресу

**2. Система тарификации**

- **Разовый тариф:** фиксированная плата за посещение
- **Посуточный тариф:** оплата за сутки с пропорциональным расчетом
- **Почасовой тариф:** гибкие временные диапазоны (0-60 мин, 60-120 мин, 120+ мин)
- Сохранение снимка тарифа для каждой сессии
- Автоматический расчет стоимости при выезде

**3. Мониторинг в реальном времени**

- Вкладка **"События":** последние 20 въездов/выездов с фото
- Вкладка **"На парковке":** список активных автомобилей с текущей стоимостью
- WebSocket-обновления без перезагрузки страницы
- Push-уведомления о новых событиях

**4. История и аналитика**

- Полная история парковок с фотографиями
- Поиск по номеру автомобиля
- Статистика: заезды за день, активные сессии, выручка
- Статистика по типам транспорта (легковые, грузовые)
- Счетчик экстренных въездов
- Экспорт данных для бухгалтерии

**5. Настройки и управление**

- **Общие настройки:** название парковки, валюта, срок хранения данных
- **Управление тарифами:** создание, редактирование, удаление тарифов
- **Управление камерами:** регистрация камер (въезд/выезд), просмотр логов
- **Белый список:** бесплатный проезд для VIP-клиентов, сотрудников, резидентов
- **Лицензирование:** активация и продление лицензий
- **Безопасность:** защита паролем доступа к настройкам

**6. Управление камерами**

- Регистрация неограниченного количества камер
- Тип камеры: въезд или выезд
- Логи камер с историей событий
- Индикация статуса подключения

**7. Белый список**

- Добавление номеров для бесплатного проезда
- Автоматическое обнуление стоимости для VIP
- Сохранение записей в базе для аудита

#### Блок "Технические особенности"

- **Desktop приложение:** работает без интернета (локальная сеть)
- **База данных SQLite:** все данные хранятся локально
- **Автообновления:** система обновляется автоматически
- **Кроссплатформенность:** Windows, macOS, Linux
- **Многоязычность:** русский, узбекский, английский интерфейсы

#### Блок "Безопасность данных"

- Все изображения хранятся в защищенной локальной базе данных
- Защита паролем доступа к настройкам
- Система лицензирования на основе Machine ID
- Ограничение размера запросов (защита от DDoS)
